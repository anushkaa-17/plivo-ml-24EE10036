For my best setup, I built a ~1.64M parameter GPT model and trained it for exactly 2000 steps. The biggest change was swapping the standard network for SwiGLU, which made the model a lot smarter without breaking the parameter limit. I also tied the input and output weights together to save space, which let me use larger embeddings. To fix the issue with multi-byte Hindi characters, I made a custom BPE tokenizer with a 512 vocab size to compress the text better. For the training loop, I used AdamW with a cosine decay and warmup for fast, stable learning. Lastly, I completely turned off dropout (set to 0.0). Since the limit is only 2000 steps, the model doesn't even have time to overfit, so dropout was literally just slowing it down. All these tweaks together gave me my lowest Dev BPB score.
